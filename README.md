# Burrow
Burrow is a private server for AJ Classic.

# Security
An independent security audit by the Strawberry Jam developer, who is not part of the Burrow team, found no malware in the Burrow client or server (client v1.2.0, server as of 17 October 2026). Every file in every installer was checked against its source and against the official Electron, NSIS and Adobe Flash releases. The report also lists the weaknesses found, with fixes, and every check can be repeated by anyone.

**[Read the audit](https://snipzil.github.io/burrow-server/)**

Every push to this repository is checked automatically (`.github/workflows/security.yml`) for new outside web addresses in the server or game files, code that starts programs, committed keys and leaked credentials.
